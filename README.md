# kibret.me

Personal portfolio for Kibret Guesh Bahta — full-stack developer.

Built with Next.js (App Router, static export), TypeScript, Tailwind CSS,
and GSAP for scroll-driven animation. Deployed to GitHub Pages via GitHub
Actions on every push to `main`.

## Stack

- Next.js 14 (static export)
- TypeScript
- Tailwind CSS
- GSAP + ScrollTrigger

## Local development

```bash
npm install
npm run dev
```
